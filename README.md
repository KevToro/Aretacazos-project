# Aretacazos — Full-Stack Business Management Platform

Aretacazos is a full-stack web application being developed for a Mexican food business in Cali, Colombia.

The project is designed to evolve from a customer-facing menu into a broader digital platform that connects customer experience with internal business management.

## Current Technology Stack

### Frontend

* React 19
* Vite
* React Router
* JavaScript (ES Modules)

### Backend

* Node.js
* Express.js
* REST APIs
* CORS
* dotenv

### Data Layer

* Supabase
* Supabase JavaScript Client

## Current Architecture

```text
Aretacazos-project/
├── frontend/
│   ├── src/
│   └── package.json
│
└── backend/
    ├── src/
    └── package.json
```

The application uses a separated frontend and backend architecture, with the frontend communicating with the backend through REST APIs.

## Current Features

* Customer registration

* Development and production build configuration

## Product Roadmap

The application is being designed to grow into a complete business management platform.

### Customer Experience

Planned functionality includes:

* Public digital menu
* Customer accounts
* Customer comments and reviews
* Interaction with menu products
* Improved customer experience and engagement

### Administrator Platform

A dedicated administrator area is planned to provide internal business management capabilities, including:

* Secure administrator authentication
* Dashboard
* Menu and product management
* Customer management
* Comment/review management
* Sales and business information
* Accounting and financial management
* Business reports

The goal is to keep the customer-facing experience simple while providing administrators with the tools required to manage the business from a centralized platform.

## Development Approach

The project follows an iterative development approach.

Features are broken down into smaller components and implemented progressively, with attention to API design, application structure, data management and testing.

AI-assisted development tools are also used during development to accelerate implementation, investigate technical problems and explore solutions. Generated code is reviewed, adapted and tested before being integrated into the application.

## Project Vision

Aretacazos is being developed as a real-world software project rather than a tutorial application.

The long-term goal is to create a platform that supports both sides of the business:

**Customers → discover the menu, interact with products and leave feedback.**

**Administrators → manage the business, customers, products and financial information.**

The architecture is being developed with this future expansion in mind.
